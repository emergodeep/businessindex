# BusinessIndex

Gratis statische Nederlandse bedrijvengids.

## Publiceren
Deze repository is geschikt voor GitHub Pages, Cloudflare Pages en Netlify.

## Structuur
- index.html — homepage en zoekfunctie
- assets/ — CSS en JavaScript
- bedrijven/ — bedrijfsprofielen
- regio/ — regiopagina's
- kennis/ — kennisartikelen
- sitemap.xml — sitemap
- robots.txt — crawlerregels

Gebruik de site als echte bedrijvengids met relevante, redactionele informatie.
